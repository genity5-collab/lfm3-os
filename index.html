Permissions

The agent can never delete anything: notes are read and write only. Everything that reaches outside this tab is handed to you as a link you tap, because a web page cannot send a message or place a call by itself.

What this is

LFM3 OS is a static GitHub Pages site. The model weights run in your browser on WebGPU through Transformers.js — there is no server doing the thinking.

Tools it actually has

  • Notes — writes and reads notes on this device and exports them to JSON. It cannot delete: that is yours, in the Notes panel.
  • Web search / read — DuckDuckGo and Wikipedia through a reader proxy, plus an optional key or your own worker.
  • Code — JavaScript in a sandboxed Web Worker with no network access.
  • Open apps — deep links to phone apps. Browsers require your tap to launch one, so the agent hands you a button.
  • Text and call — it drafts the WhatsApp or SMS message and builds the dial link. Gated by the Permissions switches, and always your tap that sends or dials.

Honest limits

  • LFM3 1.7B is small. It plans well for short tasks and drifts on long ones.
  • Deep links do nothing on desktop and some links do nothing without the app installed.
  • No background work: close the tab and the agent stops.
  • A web page cannot answer an incoming call, read your contacts, or send a message on its own. The call switch unlocks dial links; auto-answering needs a native app, not a browser.
  • Release/download buttons can't be tapped by a script — those stay your call.
